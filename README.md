# 🏏 ESPN Cricket Data Analysis Dashboard

A Power BI dashboard that provides player-wise cricket performance analysis across Batting, Bowling, and Fielding using ESPN Cricinfo statistics.

---

## 📖 Short Description

The ESPN Cricket Data Analysis Dashboard helps users explore key cricket KPIs through interactive visualizations. The dashboard includes separate pages for Batting, Bowling, and Fielding analysis with player-level filtering and performance metrics.

---

## 🛠️ Tech Stack

- 📊 Power BI Desktop
- 📂 Power Query
- 🧠 DAX (Very Minimal for this project)
- 🌐 ESPN Cricinfo StatsGuru
- 📁 PBIX & PNG Files

---

## 📈 Data Source

**Source:** ESPN Cricinfo StatsGuru

Data was collected from ESPN Cricinfo's statistics portal and includes player-level ODI cricket records covering:

- Batting Statistics
- Bowling Statistics
- Fielding Statistics

Source Link:
https://stats.cricinfo.com/ci/engine/stats/index.html

---

## ✨ Features / Highlights

### Business Problem
Cricket statistics are often presented in large tables, making it difficult to quickly analyze and compare player performance.

### Goal of the Dashboard
To provide an interactive and easy-to-understand view of player performance across batting, bowling, and fielding disciplines.

### Key Visuals

#### 🏏 Batting Analysis
- Runs
- Strike Rate
- Average
- Highest Score
- 4s & 6s
- Centuries & Half Centuries

#### 🎳 Bowling Analysis
- Wickets
- Economy
- Bowling Average
- Strike Rate
- Maiden Overs
- Best Bowling Figures

#### 🧤 Fielding Analysis
- Catches
- Stumpings
- Dismissals
- Catches as Fielder
- Catches as Wicket Keeper

### Business Impact
- Simplifies player performance analysis.
- Enables quick comparison of cricket statistics.
- Demonstrates Power BI data visualization and analytical skills.
